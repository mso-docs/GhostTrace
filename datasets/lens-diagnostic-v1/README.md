# Small affine-lens implementation diagnostic

32 original synthetic generic prompts, separate from the 30 persona scenarios. The first24 unique topic groups are development and the final8 different topic groups are held out. These prompts are AI-assisted and not independently human reviewed. CC0-1.0.

This is a bounded software/training diagnostic, not a representative language corpus or evidence that the fitted lens generalizes. Holdout vectors never enter optimization. The actual predictive-KL objective, training settings, weights, loss and held-out values must be reported. No semantic feature or model-thought claim follows from these readouts.
