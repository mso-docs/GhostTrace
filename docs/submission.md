# Release and submission evidence

This repository is an implementation, not proof of experimental results. Before describing it as a research-ready release, complete docs/acceptance.md. Do not publish a fixture as a measured experiment, and do not imply a DEV draft is a submitted entry.

A release evidence packet should contain: source commit and licenses; frozen protocol/config/dataset/model hashes; hardware preflight; real smoke inventory; full or explicitly reduced pilot; all failures/exclusions; blinded rating status; real read-only replay bundle; environment; checksummed export; tested offline replay; accessibility verification; and a short demonstration.

The pasted specification mentions a challenge deadline conflict. Challenge eligibility, official template, exact deadline, attribution and disclosure requirements must be verified with the current canonical rules before submission. No submission or public article is created by this repository.

Record deviations before running: selected smaller model, reduced scenario count, omitted optional features, one-rater status, or exploratory reclassification. Do not hide unsuccessful runs, nulls or missing controls.
